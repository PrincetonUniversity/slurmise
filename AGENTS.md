# Agent Context for slurmise

This file provides project conventions for AI coding assistants. See `AI_POLICY.md` for the project's contribution policy.

## Project overview

`slurmise` is a Python library and CLI for estimating Slurm HPC job resource requirements (CPU, memory, time) by fitting models to historical job data. It queries `sacct`, stores job records in HDF5, and fits scikit-learn models to predict future resource needs.

Key concepts:
- **Job specification**: a named workflow with an associated input parser and resource fit model.
- **Job database**: HDF5-backed store of historical sacct records (`src/slurmise/job_database.py`).
- **Fit models**: sklearn wrappers in `src/slurmise/fit/` (polynomial, k-neighbors).
- **Extras**: optional Snakemake integration in `src/slurmise/extras/` — only used when snakemake is installed.

## Development setup

This project uses [`uv`](https://docs.astral.sh/uv/) for environment management.

```bash
uv sync --all-groups          # install all dependency groups
uv run pre-commit install      # install pre-commit hooks
```

## Running tests and checks

Tasks are defined via [poethepoet](https://poethepoet.namazie.com/):

```bash
uv run poe test        # pytest with coverage and random ordering
uv run poe check       # mypy type checking
uv run poe fmt-check   # ruff format check + ruff lint
```

To auto-fix formatting:

```bash
uv run ruff format .
uv run ruff check --fix .
```

Snakemake integration is tested separately against multiple Snakemake versions:

```bash
uv run poe smk-test-v7   # snakemake 7.x, Python 3.11
uv run poe smk-test-v8   # snakemake 8.x, Python 3.12
uv run poe smk-test-v9   # snakemake 9.x, Python 3.13
```

## Code conventions

- **Line length**: 120 characters (enforced by ruff).
- **No relative imports**: all imports must be absolute (enforced by ruff `ban-relative-imports = "all"`).
- **Type annotations**: required for function arguments and return values (checked by mypy). A few ruff rules are relaxed for tests — see `pyproject.toml` `[tool.ruff.lint.per-file-ignores]`.
- **Comments**: only when the *why* is non-obvious. Avoid describing what the code does.

## Generated files

- `src/slurmise/__about__.py` — generated by `setuptools-scm` from git tags; do not edit manually.

## Gotchas

- Slurm queries (`sacct`, `squeue`) are mocked in tests via fixtures in `tests/conftest.py`. Real Slurm is not required to run the test suite.
- The `extras/` subpackage is excluded from coverage reporting because it requires an optional snakemake dependency.
- Tests run in random order (`pytest-random-order`) — do not rely on test execution order or shared mutable state between tests.
